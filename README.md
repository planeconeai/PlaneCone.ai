# Planecone Mammography AI Microservice (Mammo-CLIP Research Prototype)

This microservice provides zero-shot mammography image-text alignment scores using the **Mammo-CLIP** foundation model ([shawn24/Mammo-CLIP](https://huggingface.co/shawn24/Mammo-CLIP) / [BATMAN Lab](https://github.com/batmanlab/Mammo-CLIP)).

## 1. Overview & Capability

* **Model Checkpoint:** `shawn24/Mammo-CLIP` (Hugging Face)
* **Model Task:** Zero-shot image-text retrieval & text alignment scoring
* **Supported Concepts:** `mass`, `suspicious_calcification`, `architectural_distortion`, `asymmetry`, `normal`
* **Score Type:** `zero_shot_text_alignment` (relative cosine similarity across text prompts).
* **Clinical Diagnosis:** **NOT SUPPORTED**. Outputs are NOT calibrated clinical probabilities, BI-RADS scores, or pathological diagnoses.

## 2. API Endpoints

### `GET /health`
Exposes service health status, PyTorch model load state, and active device.

```json
{
  "status": "ok",
  "model_loaded": true,
  "model": "Mammo-CLIP",
  "checkpoint": "shawn24/Mammo-CLIP",
  "device": "cpu",
  "error": null
}
```

### `GET /model-info`
Provides transparent model metadata, task specifications, and licensing terms.

```json
{
  "name": "Mammo-CLIP",
  "checkpoint": "shawn24/Mammo-CLIP",
  "model_type": "vision-language foundation model",
  "task": "image-text retrieval / zero-shot text alignment",
  "clinical_diagnosis": false,
  "calibrated_probability": false,
  "license": "CC BY-NC-SA 4.0 (Non-Commercial Research Only)"
}
```

### `POST /predict`
Accepts DICOM mammography files (`Modality=MG`), validates `StudyInstanceUID` consistency, and returns per-view zero-shot text alignment scores.

**Example Request:**
```bash
curl -X POST http://localhost:8000/predict \
  -F "files=@right_cc.dcm" \
  -F "files=@right_mlo.dcm" \
  -F "files=@left_cc.dcm" \
  -F "files=@left_mlo.dcm"
```

**Example Response:**
